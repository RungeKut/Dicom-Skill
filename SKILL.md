# Медицинская визуализация: разбор снимков скриптами

Корень набора — папка, из которой прочитан этот файл (клон
`RungeKut/Dicom-Skill`); соседние скиллы — рядом с ней. База `knowledge/`
(карта и поиск по симптому — `INDEX.md`). Общие правила — соседний скилл
skill-skill.

**Первым делом:** `git -C <корень> pull --rebase`; конфликт — разобрать до
работы.

```python
import sys; sys.path.insert(0, r"<корень>")
import dicomkit as dk
dk.inventory(r"<путь к DICOM>")            # таблица серий + покрытие
ser = dk.load_series(r"<...\SE000006>")    # срезы, отсортированы по положению
dk.montage(ser, r"<out>\m.png")            # обзорный лист серии
dk.asymmetry_report(ser, r"<out>")         # зеркальные карты право/лево
```

## Железные правила

1. Срезы сортировать ТОЛЬКО по проекции IPP на нормаль среза (30-01):
   порядок каталога/InstanceNumber перемешивает стороны и позиции.
2. Отчёт всегда помечен «предварительный автоматизированный разбор, НЕ
   является врачебным заключением» (20-05); трактовка — за врачом.
3. Данные пациента (имена, ID, даты) не попадают в набор и его коммиты
   (40-02): отчёты — в рабочую папку пользователя, не в репозиторий.
4. GIF/вложения в PDF — последним шагом через pypdf; повторное
   пересохранение чужими утилитами их теряет (30-02).
5. Ориентацию среза проверять по доминантной оси столбцового вектора
   и глазами (глазницы/лоб сверху на аксиальных) — 10-03, 30-04.

Три прохода разбора, мм-сетки, GIF из фаз — 20-01…20-05; «битые» диски
Siemens — 30-01…30-05, 40-01.
