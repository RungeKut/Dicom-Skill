# Чтение серий DICOM

## Стандартный путь

```python
ser = dk.load_series(r"<папка серии>")   # dicomkit/io.py
arr = ser[i].pixel                       # numpy float
```

`load_series` читает каждый файл, извлекает пиксели, применяет ориентацию
(10-03) и возвращает срезы, отсортированные по проекции IPP на нормаль
среза (30-01).

## «Битые» диски: JPEG-Lossless без терминатора

**Что происходит:** на части пациентских дисков Siemens пиксельный элемент
(7FE0,0010) обёрнут в Items (FFFE,E000), но закрывающий разделитель
(FFFE,E0DD) отсутствует. pydicom при полном чтении отбрасывает весь
датасет (30-03): `PixelData` отсутствует, Rows/Columns пусты, тегов 0.

**Как правильно:** метаданные — `dcmread(..., stop_before_pixels=True,
force=True)`; пиксели — ручное извлечение: найти `b"\xe0\x7f\x10\x00"`,
разобрать Items `FFFE,E000` (первый может быть пустым BOT), склеить и
декодировать `from pylibjpeg import decode`. Это реализовано в
`dicomkit/io.py` — читать только через него.

**Как неправильно:** пытаться `ds.pixel_array` напрямую или пересохранять
«починенный» файл — заголовки и порядок Items различаются между дисками.

**Чем подтверждено:** два диска Siemens, все серии конвертированы в PNG
без потерь (2026-11).
