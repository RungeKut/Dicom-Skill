# Правила базы знаний

**Общие правила — соседний скилл skill-skill, `knowledge/00_ПРАВИЛА.md`**:
что хранить, структура 10_/20_/30_/40_, шапка записи и статусы, добавление
и удаление, SKILL.md и установка, проверка целостности, язык. Работа с
репозиторием — там же, 40-02.

## Особенности набора

* `applies_to` — ОС Windows, Python 3.12+ (py-лаунчер), dicomkit версии
  из коммита; модальности МРТ/КТ и скриншоты УЗИ.
* Хранить: поведение производителей томографов и просмотрщиков,
  расходящееся со стандартом DICOM; приёмы анализа снимков, доказавшие
  работоспособность; параметры методик (окна контраста, пороги карт
  асимметрии), подобранные опытом.
* Не хранить: данные пациентов и исследования, по которым набор
  применялся (40-02); клинические трактовки (их делает врач, набор —
  визуализация и измерения).
* Каждый PDF-отчёт набора обязан нести дисклеймер «предварительный
  автоматизированный разбор, НЕ является врачебным заключением» (20-05).
* Изображения-примеры под git — только обезличенные, в `examples/`.
