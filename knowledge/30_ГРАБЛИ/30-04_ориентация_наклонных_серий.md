# Ориентация наклонных серий

**Что происходит:** универсальное правило «если col[2]>0, флипнуть по
вертикали» даёт перевёрнутую картинку на сериях, где столбцовый вектор
направлен вдоль +Y (наклонные аксиальные, некоторые реконструкции):
анатомия оказывается вверх ногами, глазницы внизу.

**Почему:** у наклонных серий «вертикаль» экрана может идти вдоль любой
пациентской оси; знак флипа зависит от доминантной оси вектора.

**Как правильно:** ось = аргумент максимума `|col|`; флип по правилу
доминантной оси (10-03); результат проверять глазами до использования.
Горизонталь (право/лево на экране) — только после проверки анатомии и
знака row-вектора.

**Как неправильно:** доверять флипу «по z» для всех серий; выводить
панели не глядя.

**Чем подтверждено:** перевёрнутая CISS-серия обнаружена при просмотре,
исправлена по новому правилу, все остальные серии прошли проверку.
