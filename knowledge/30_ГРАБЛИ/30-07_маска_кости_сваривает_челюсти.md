# Маска кости сваривает челюсти при контакте зубов

**Что происходит:** в КЛКТ при смытом прикусе контакт зубов (и плотных
реконструкций) соединяет нижнюю челюсть с верхней, скуловой дугой и
основанием черепа в одну связную компоненту. «Вершина компоненты
мандибулы» оказывается скуловой дугой или дном черепа, а не мыщелком.
Суставная щель тоже может «завариться» порогом с шумом. Шум КЛКТ
дополнительно порождает тысячи одно-воксельных компонент.

**Как правильно:** компоненты фильтровать по размеру (гиганта-череп
исключать, мелочь < порога отбрасывать); мыщелки искать геометрией:
разрез объёма по щелевой плоскости (зона контакта зубов) с сопоставлением
над- и подплоскостных фрагментов по (x,y); либо по-пиксельные вертикальные
профили столбиков — «два сегмента кости с разрывом ≥1 мм = суставная
зона» — но в узком боксе: ANY() по широкому боксу склеивает все сегменты
в один непрерывный профиль.

**Как неправильно:** labeling по маске кости → «самая большая компонента
= мандибула» → её максимум по z = мыщелок; брать ANY() по широкой колонке
и искать в профиле разрыв.

**Чем подтверждено:** связность дала «вершину» на границе ограничения
области (z=119.8 при кэпе 120) и совпадающий апекс для обеих сторон;
геометрический подход локализовал оба мыщелка точно и симметрично
(межмыщелковое ~104 мм, согласуется с шириной тела челюсти).
