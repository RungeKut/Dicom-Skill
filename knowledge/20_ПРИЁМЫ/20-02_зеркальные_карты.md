# Зеркальные карты асимметрии право/лево

`dk.asymmetry_report(series, out)`: для каждого среза гауссова
предобработка, поиск средней линии (перебор колонок с минимизацией
расхождения с зеркалом), вычитание зеркала, порог по 99-му перцентилю
внутри тканевой маски, разметка блобов связных областей (scipy.ndimage),
топ-N по площади с площадью в мм².

**Чтение результата:** блобы, образующие зеркальные пары относительно
средней линии, — симметричные структуры (норма). Односторонние
структурированные блобы — находка или артефакт: каждый разбирать на
поштучных срезах, прежде чем заявлять.

**Ограничения:** наклон головы смещает среднюю линию (карта шумит по
краям); борозды, сосуды и полюса долей дают крупные нормальные различия —
отбирать только округлые однородные блобы, остальные проверять
визуально. Чувствительность к мелким очагам ниже просмотра врачом —
карта скрининговая.

**Чем подтверждено:** все крупные блобы двух исследований разобраны
поштучно — однородных очагов не найдено, зеркальные пары подтверждены.
