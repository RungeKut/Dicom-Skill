# GIF-динамика из серий

Два вида серий движения:

1. **Пошаговые позиции** (шаблон повторяется N раз с пустым описанием):
   ключ группировки — (описание серии, AcquisitionNumber, сторона);
   внутри позиции выбирать центральный срез по проекции IPP. Центры
   срезов совпадают между позициями — сравнение в одной плоскости
   корректно.
2. **Cine (реальное время)**: cine = несколько кадров на одном и том же
   срезе (совпадающая проекция IPP); сортировка по AcquisitionTime.
   Обычные многосрезовые серии (у каждого среза своя позиция) в cine не
   попадают — группировка только по описанию ошибочно смешивает срезы.

**Как правильно:** GIF собирать только из реальных кадров, без
интерполяции промежуточных фаз (дорисовка = выдуманная картинка); цикл
«закрыт → открыт → закрыт», длительности кадров по роли позиции
(концевые длиннее). В отчёте указывать дискретность шагов.

**Чем подтверждено:** собраны и проверены обе анимации; шаги между
позициями видны и объяснены в отчёте.
