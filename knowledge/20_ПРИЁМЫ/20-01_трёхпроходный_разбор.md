# Трёхпроходный разбор

1. **Обзорный** — конвертация всех серий в PNG, монтаж-обзоры, просмотр
   глазами: грубая патология, зоны неуверенности (список У1…Уn с «где
   смотреть» и «что сделать»).
2. **Целевой по показаниям** — если есть жалобы/вопрос: зеркальные карты
   асимметрии (20-02), ROI, прицельные уровни нервов и каналов.
3. **Измерительный** — мм-сетки на верифицированных срезах (20-03),
   количественные значения вместо «погранично».

Итог — один сводный PDF: паспорт, методы всех проходов, находки с
плейтами, сводная таблица «жалоба → данные → статус», зоны неуверенности,
направления дообследования (вопросы к врачу, не назначения), дисклеймер
(20-05). Каждый следующий проход не отменяет предыдущий, а уточняет;
поправки формулировать явно («ранее записано X, уточнено Y»).

**Чем подтверждено:** полный цикл (три прохода + дополнение по терапии)
на паре исследований одного дня.
