# Координаты: численно, панели — иллюстрация

**Проблема:** на зумированных панелях с кропом легко спутать сдвиг кропа с
координатой: подписи сеток идут от угла кропа (20-03), при zoom 3–4 и
нескольких уровнях кропов глазная съёмка даёт ошибки в **десятки мм**. В
практике дважды: апекс зубной дуги по панели «x≈65 мм» (численно — 90 мм);
«мыщелок» по сагиттальной полосе оказался уровнем основания черепа.

**Как правильно:** количественные утверждения — численно по маске (порог
кости → центроид / крайний кластер / вертикальные профили), мм-сеточные
панели — для визуальной верификации и иллюстрации в отчёте. Численное и
«глазное» значения расходятся → искать ошибку до публикации, не выбирать
«какое больше нравится».

**Как неправильно:** измерять по панели и писать в отчёт; совмещать в одном
предложении координаты от разных источников без сверки.

**Чем подтверждено:** расхождение панель/маска на 25 мм по апексу дуги;
численный расчёт (крайний кластер маски >1500 HU) дал согласованную с
костными ориентирами среднюю линию; после этого панели использовались
только для проверки.
