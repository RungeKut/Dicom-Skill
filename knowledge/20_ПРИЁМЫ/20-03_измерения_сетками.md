# Измерения по мм-сеткам

`dk.grid_panel(pixel, crop, pixel_spacing, zoom, title, grid_mm)` — панель
с сеткой: координаты снимаются глазами, расстояния считаются в мм от
начала кадра. Точность ±1–2 мм; заявлять её в отчёте. Оговорка (20-07):
на зумированных панелях с кропом подписи сеток идут от угла кропа —
без численной привязки глазная съёмка даёт ошибки в десятки мм; отчётные
метрики брать численно по маске, панель — для верификации и иллюстрации.

**Методика на примере смещения диска сустава:** центр утолщённой задней
зоны диска относительно вершины мыщелка («12 часов»); смещение = сдвиг по
горизонтали, угол — от вертикали. Формулировка в отчёте: «≈5 мм кпереди,
положение "10–11 часов"».

**Как неправильно:** сравнивать экранные координаты структур между
сериями, снятыми в разных плоскостях (закрытый/открытый рот) — плоскости
разные, любой сдвиг на экране может быть артефрактом ракурса.
Кросс-плоскостное движение оценивать только качественно или через 3D по
IPP (фазовая корреляция по регионам даёт мусор).

**Чем подтверждено:** измерения положений дисков двух суставов; попытка
фазовой корреляции между плоскостями дала противоречивые векторы.
