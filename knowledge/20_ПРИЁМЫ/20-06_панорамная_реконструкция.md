# Панорамная реконструкция по кривой дуге

**Рецепт:** контрольные точки дуги в мм пациента снять с окклюзионного
аксиального среза (апекс + задние концы); сгладить Catmull-Rom, шаг ~0.8 мм.
Вдоль кривой — вертикальные плоскости по нормали; из каждой взять **тонкую
пластину ±2 мм и усреднить** (классический вид панорамы). Окно костное.
Первая точка дуги = правый конец — останется слева на панораме (как в
стоматологических вьюерах).

Код: `dicomkit.pano.panorama(vol, points, z0, z1, sp_xy, sp_z, slab=2, half=30)`
— на вход объём vol[z,y,x] (см. 30-06 про раздельные шаги осей), на выходе
массив (вдоль дуги, z; верх = больший z) — окно и подписи поверх.

**Как неправильно:** MIP по широкой полосе (±30 мм) — пересвечивается в
белый сплошняком (каждая колонка ловит плотную кость на каком-то z);
широкий mean — смазывает корни. И задавать один шаг осей для всех трёх
размерностей (30-06).

**Чем подтверждено:** панорамы обеих челюстей из КЛКТ — зубные ряды,
реставрации, дефекты дуги и корни читаются; листы прошли макетную приёмку
отчёта. MIP-вариант отбракован визуально (белый лист).
