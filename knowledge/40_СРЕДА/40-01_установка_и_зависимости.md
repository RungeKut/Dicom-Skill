# Установка и зависимости

```bash
py -m pip install pydicom numpy pillow scipy pylibjpeg pylibjpeg-libjpeg reportlab pypdf pymupdf
```

* **Python на Windows** — через py-лаунчер: `python` может быть заглушкой
  Microsoft Store (см. skill-skill 30-02).
* **pylibjpeg + pylibjpeg-libjpeg** — декодер JPEG-Lossless для «битых»
  дисков (10-01); без него чтение пикселей таких дисков невозможно.
* **reportlab, pypdf, pymupdf** — PDF-конвейер (20-05); обложка и
  QA-конвейер берутся из соседнего скилла pdf — пути его инструментов
  в набор не записываются, смотрите его SKILL.md.
* **scipy** — связные области и сглаживание карт асимметрии (20-02).
* Шрифты для PDF — Times из системной папки Windows; путь собирается из
  `WINDIR` (необязательная переменная с умолчанием `C:\Windows`),
  запасной вариант — штатный шрифт reportlab.

Настройки окружения помимо этого набору не нужны; `*_HOME`-переменных
нет и не должно появляться (skill-skill 30-01).
