# Dicom-Skill

Разбор медицинских снимков скриптами: МРТ и КТ (пациентские DICOM-диски),
изображения УЗИ. Библиотека `dicomkit` на Python: инвентаризация серий с
проверкой покрытия, конвертация в PNG (включая «битые» диски Siemens с
JPEG-Lossless без терминатора), обзорные монтажи, зеркальные карты
асимметрии право/лево, измерения по мм-сеткам, GIF-динамика из фазовых
серий и cine, сводный PDF-отчёт с зонами неуверенности. Скилл агента
`dicom`: клон репозитория и есть папка скилла.

Каждый отчёт набора помечается «предварительный автоматизированный разбор,
НЕ является врачебным заключением»; клинические трактовки остаются за
врачом. Данные пациентов в репозиторий не попадают.

Общие правила ведения, проверки и хук — соседний скилл
[Skill-Skill](https://github.com/RungeKut/Skill-Skill).

```
dicom/                      клон Dicom-Skill в папке скиллов агента
├── SKILL.md                точка входа для ИИ
├── dicomkit/               библиотека Python
│   ├── io.py               чтение серий, ориентация, сортировка по IPP, «битые» диски
│   ├── montage.py          обзорные листы и поштучные PNG
│   ├── asymmetry.py        зеркальные карты асимметрии право/лево
│   ├── measure.py          мм-сетки для измерений
│   ├── gifstack.py         GIF из фазовых серий и cine
│   └── report.py           PDF-отчёт: каркас, обложка, GIF-вложения
├── knowledge/              база проверенного знания (INDEX — карта и поиск по симптому)
├── tools/                  обёртка общей проверки, локальный стоп-лист
└── examples/               обезличенные примеры под git
```

## Установка

```bash
git clone https://github.com/RungeKut/Dicom-Skill.git "<папка скиллов агента>/dicom"
```

Рядом нужен скилл skill-skill (общие правила, проверки, хук). Зависимости
и настройка клона — `knowledge/40_СРЕДА/40-01`.
